# Developer Reference: AltixEdu Frontend Specification

This document is your complete guide for building the AltixEdu frontend. It covers all screens, flows, UI elements, and integration points. Use it as your single source of truth.

## 1. User Roles & Access

- **Roles:**
  - Superadmin
  - Ministry Admin
  - School Admin
  - Teacher
  - Student
  - Parent
  - Bursar

- **Role-based Navigation:**
  - Each role sees only their permitted features.
  - Dynamic menus and dashboards per role.

## 2. Authentication Flows

- **Login:**
  - General login (username/email + password)
  - Ministry admin login (email + password, POST /api/auth/login/ministry/)
  - Show error messages for invalid credentials.

- **Password Reset:**
  - Self-reset (old password + new password)
  - Admin-forced reset (email + new password)
  - Show confirmation and error messages.

- **Token Handling:**
  - Store token securely (localStorage or sessionStorage)
  - Attach token to all API requests.

## 3. Dashboard Screens

- **Superadmin Dashboard:**
  - Overview of all ministries, schools, users.
  - Create ministry admin, create school.
  - View system statistics.

- **Ministry Admin Dashboard:**
  - Ministry info (country, state, currency)
  - State dashboard: statistics, school list, reports, finances.
  - Approve/reject requests, view audit logs.

- **School Admin Dashboard:**
  - School info, staff, students, classes, attendance, finances.
  - Manage school profile, add/edit users.

- **Other Roles:**
  - Teacher: class management, attendance, grades.
  - Student: profile, grades, attendance.
  - Parent: child info, attendance, grades.
  - Bursar: finance dashboard, billing.

## 4. School Setup Flow

- **Create School Form:**
  - Fields: name, subdomain, email, phone, address, city, state, country.
  - Validate required fields, uniqueness (subdomain, email).
  - Show confirmation on success, error on failure.
  - Only superadmin/ministry admin can access.

## 5. Ministry Admin Features

- **Dedicated Login Page:**
  - POST /api/auth/login/ministry/
  - Show ministry context after login (country, state, currency).

- **State Dashboard:**
  - List all schools in state.
  - View state statistics, reports, finances.
  - Approve school requests, manage state-level permissions.

- **Permissions:**
  - View dashboard, schools, statistics, reports, finances, approvals, audit logs.

## 6. Multi-Country & State Support

- **Country Selection:**
  - Support for Nigeria, Kenya, Ghana, South Africa (expandable).
  - Show country and state/province in all relevant screens.

- **Currency Display:**
  - Show currency code and symbol per country.

## 7. UI & UX Requirements

- **Responsive Design:**
  - All screens must work on desktop, tablet, and mobile.

- **Modern UI:**
  - Use clean layouts, accessible color schemes, clear typography.
  - Use cards, tables, modals, and form elements.

- **Error Handling:**
  - Show clear error messages for all failed actions.
  - Display backend error messages (400, 403, 500).

- **Success Feedback:**
  - Show confirmation messages for successful actions.

## 8. API Integration

- **Endpoints to Integrate:**
  - POST /api/auth/login/
  - POST /api/auth/login/ministry/
  - POST /api/auth/create-ministry-admin/
  - POST /api/auth/reset-password/
  - POST /api/schools/setup/
  - GET /api/dashboard/*
  - GET /api/government/*
  - GET /api/billing/*

- **Request/Response Handling:**
  - Validate all responses, handle errors, show messages.

## 9. Data Validation

- **Forms:**
  - Required fields, email format, password strength, state selection.
  - Prevent duplicate subdomain/email on school creation.

## 10. Testing & Quality

- **Manual Testing:**
  - Test all flows: login, school setup, ministry dashboard, error scenarios.

- **Automated Testing (Optional):**
  - Add unit tests for form validation and API integration.

## 11. Documentation & Help

- **User Guides:**
  - Provide onboarding instructions for each role.

- **Error Explanations:**
  - Show clear messages for failed actions.

## 12. Future Features (Optional)

- **Bulk Import:**
  - CSV upload for users/schools.

- **Multi-language Support:**
  - UI translation for major languages.

- **Audit Logging:**
  - Display audit logs for ministry admins.

- **Health/Medical Records:**
  - Add health record screens for students.

## School Creation: All Required & Optional Fields

### Required Fields (must be filled)
- name (string)
- subdomain (string, unique)
- email (string, unique)
- phone (string)
- address (string)
- city (string)
- state (string)
- country (string)

### Optional/Advanced Fields (recommended for full setup)
- postal_code (string)
- website (string)
- timezone (string, default: 'UTC', e.g., 'Africa/Lagos')
- language (string, default: 'en')
- school_type (string, default: 'private', choices: private, public, international, etc.)
- region (string, for geographic templates)
- established_year (integer)
- is_active (boolean, default: True)
- primary_color (string, hex, default: '#0066CC')
- secondary_color (string, hex, default: '#FF6600')

### Implementation Checklist
- All required fields must be validated and collected
- Optional fields should be included in the form for advanced setup
- Validate uniqueness for subdomain and email
- State must be enforced and confirmed in response
- School_type, region, established_year, colors, and is_active can be set for richer school profiles

# Ministry Admin: School Creation Flow

- **Ministry Admin Dashboard**
  - Ministry Admins can create schools from their dashboard.
  - Endpoint: POST /api/schools/setup/
  - Fields required: name, subdomain, email, phone, address, city, state, country
  - State is auto-filled or restricted to ministry admin's assigned state.
  - Validation: All fields required, subdomain/email unique, state enforced
  - Permissions: Ministry Admin can only create schools in their assigned state
  - Error Handling:
    - 400: Missing fields or duplicate subdomain/email
    - 403: Attempt to create school outside assigned state
  - Success: 201 Created, confirmation message, school listed in state dashboard

- **Ministry Admin School Management**
  - View all schools in their assigned state: GET /api/government/schools/?state=<assigned_state>
  - Edit school profile: PUT /api/schools/<school_id>/profile/
  - Approve/reject school requests (if applicable)

## Permissions & Access Control

- **Superadmin:**
  - Full access to all features, users, schools, ministries, billing, reports, settings
- **Ministry Admin:**
  - Access to state dashboard, schools in state, statistics, reports, finances, approvals, audit logs
- **School Admin:**
  - Access to own school, staff, students, classes, attendance, finances, settings
